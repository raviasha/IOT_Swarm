User Manual
Configure Your Network

Use the sliders on the left panel to set:

  • Number of Nodes: How many IoT devices to simulate (5-50)
  • Packet Loss Rate: Percentage of messages that will fail (0-80%)
  • Message Frequency: How often nodes send messages (1-10/sec)
  • Communication Range: Maximum distance for node connections (50-200)
Initialize the Network

Click "Initialize Network" to create nodes. They are placed randomly and connections are established based on communication range. The network topology is shown in the visualization.

Run the Simulation

Use the playback controls:

  • Play: Start the simulation
  • Pause: Pause at current time
  • Stop: Reset to beginning
  • Step: Move one event at a time
  • Speed: 0.25x to 4x playback speed
  • Timeline: Drag to jump to any point in time
Understanding the Visualization
Nodes:
  • Purple = Idle
  • Green = Sending a message
  • Yellow = Receiving a message
Packets:
  • Green dot = Will be delivered
  • Red dot = Will be dropped
Statistics
  • Sent: Total messages generated
  • Delivered: Messages successfully received
  • Dropped: Messages lost due to packet loss
  • In Flight: Messages currently traveling
  • Delivery Rate: Percentage of successful deliveries
  • Avg Latency: Average time for message delivery
