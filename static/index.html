1. Introduction

Welcome to the P2P Swarm Model - a software-only simulation of peer-to-peer communication networks for IoT (Internet of Things) devices.

What is this? This is a research and educational tool that simulates how IoT devices communicate in a mesh network without requiring any physical hardware.
Key Features:
  • Virtual Nodes - Simulated IoT devices that can send and receive messages
  • Network Simulation - Realistic network conditions including packet loss and delays
  • Gossip Protocol - Messages spread through the network like rumors
  • Visual Feedback - See your network topology and watch messages propagate

2. System Overview

How It Works:
Nodes
Virtual IoT devices with unique IDs and positions
Network
Simulated wireless connections between nearby nodes
Messages
Data packets that hop from node to node
Dashboard Statistics:
Statistic Description
Total Nodes Number of virtual IoT devices in the network
Connections Total number of links between neighboring nodes
Messages Delivered Successfully received messages across all nodes
Packet Loss Percentage of messages lost during transmission

4. Running Simulations

Simulation Parameters:
Parameter Range Description Recommendation
Number of Nodes 2 - 100 How many virtual devices to create Start with 20-30 for testing
Packet Loss (%) 0 - 100% Chance that a message fails to deliver 10-20% for realistic conditions
Runtime (seconds) 1 - 60 How long the simulation runs 10-30 seconds for quick tests
Communication Range 10 - 300 How far a node can "reach" others 100-150 for normal density
Understanding Results:
  • Delivery Ratio - Percentage of messages that reached their destination (higher is better)
  • Messages Sent - Total messages generated during simulation
  • Messages Delivered - Messages that successfully arrived
  • Packets Dropped - Messages lost due to network conditions

5. Viewing Nodes

The "View Nodes" tab shows all virtual devices in your network.

Network Visualization:
  • Red dots - Individual nodes (IoT devices)
  • Blue lines - Connections between neighboring nodes
  • Hover over nodes - See node ID and details
Node Information:
  • Node ID - Unique identifier (e.g., node_001)
  • Position - X, Y coordinates in the virtual world
  • Neighbors - Other nodes within communication range
  • Stats - Messages sent, received, and delivered
Tip: Click "Refresh" to update the node list after running a simulation.

6. Sending Messages

The "Send Message" tab lets you inject custom messages into the network.

Message Fields:
From Node Select which node sends the message (or leave as "Random")
To Node Select destination (or leave as "Broadcast" for all nodes)
Urgency Priority level: Low (0) to Emergency (5)
Message Content Your custom message text or data
Urgency Levels:
0 - Lowest
1 - Low
2 - Normal
3 - High
4 - Critical
5 - Emergency

7. Network Control

The "Network Control" tab provides advanced network management.

Available Actions:
Reset Network

Recreate all nodes with new random positions. Use this to start fresh.

Create Partition

Split the network into isolated groups. Simulates network failures or geographic separation.

Heal Partition

Reconnect all partitioned groups. Restores full network connectivity.

What is a Partition? A network partition occurs when a group of nodes becomes isolated and cannot communicate with the rest of the network. This simulates real-world scenarios like cable cuts or equipment failures.

8. Glossary

Node
A virtual IoT device in the simulation
Swarm
A collection of nodes working together
P2P (Peer-to-Peer)
Direct communication between nodes without a central server
Gossip Protocol
Message spreading technique where nodes share information with neighbors
TTL (Time-to-Live)
Maximum number of hops a message can take before expiring
Packet Loss
When messages fail to reach their destination
Partition
Network split where groups cannot communicate
Delivery Ratio
Percentage of messages successfully delivered
Communication Range
Maximum distance for two nodes to connect
Broadcast
Sending a message to all nodes in the network
